# CLI V3

> What V3 adds to Kiro CLI: the shared agent harness, its new capabilities, and where each capability is documented.

Kiro CLI V3 is the current CLI experience. For the day-to-day CLI documentation, start at [CLI](https://kiro.dev/docs/cli.md).

## A single harness for all Kiro surfaces

CLI V3 uses the same [unified agent harness](https://kiro.dev/docs/how-kiro-works.md) as Kiro IDE and Kiro Web. This brings shared agent-loop improvements to the terminal and lets supported `.kiro` configuration travel between surfaces. Some tools, commands, and configuration fields remain surface-specific; the tables below identify the supported V3 path.

## What's new in V3

**Spec-driven development**: The Spec agent brings structured development to the terminal. Define requirements, generate designs, execute task plans. Use `/spec new <name>` to start. [Learn more →](https://kiro.dev/docs/specs.md)

**Capability-based permissions**: Declare structured policies in `permissions.yaml` for fine-grained, auditable control. One rule can allow or deny an entire category of operations across all tools. [Learn more →](https://kiro.dev/docs/permissions.md)

**Enhanced hooks**: Standalone `.kiro/hooks/*.json` files with two action types (shell commands and agent prompts), new triggers, and a versioned schema. [Learn more →](https://kiro.dev/docs/hooks.md)

**Enhanced agent config**: Tag-based tool selection, unified permissions block, Markdown format, inline MCP servers. [Learn more →](https://kiro.dev/docs/custom-agents.md)

**Introspect sub-agent**: Ask Kiro about its own features and it answers from the official documentation. [Learn more →](https://kiro.dev/docs/custom-agents/built-in.md#introspect-sub-agent)

**Workflows**: Run multi-step work in the background while the main conversation stays available. Turn it on with the `chat.enableWorkflows` setting and restart Kiro CLI. [Learn more →](https://kiro.dev/docs/workflows.md)

**Tangent**: Branch your conversation into side-conversations that inherit your context, explore freely, then jump back to exactly where you left off. Use `/tangent` to branch. [Learn more →](https://kiro.dev/docs/cli/chat/tangent.md)

The table tracks current V3 support across core CLI workflows and capabilities that exist only on the shared harness. "Available" means the reader task has a supported V3 path.

| Area | V3 status | What is available now | Details |
|------|:---------:|-----------------------|---------|
| **Chat and terminal UI** | Available | Markdown rendering, tool cards, Preserve scrollback, live progress, and fullscreen chat | [Terminal UI](https://kiro.dev/docs/cli/terminal-ui.md) |
| **Prompt input** | Available | File references, image paths and clipboard images, queued messages, and multi-line editing | [Working with images](https://kiro.dev/docs/cli/chat/images.md), [File references](https://kiro.dev/docs/cli/chat/file-references.md) |
| **Settings and display** | Available | Global and workspace settings, ASCII mode, custom busy indicators, shared or per-session history, and scrollback control | [In-session settings](https://kiro.dev/docs/cli/chat/settings.md), [Settings reference](https://kiro.dev/docs/reference/settings.md) |
| **Models and reasoning** | Available | Session model selection plus Thinking and Effort controls in `/model`, with explicit saved defaults | [Models](https://kiro.dev/docs/models.md), [Reasoning effort](https://kiro.dev/docs/models/effort.md) |
| **Documentation help** | Available | An introspect sub-agent answers questions about Kiro features from the official documentation | [Built-in agents](https://kiro.dev/docs/custom-agents/built-in.md#introspect-sub-agent) |

| **Tangent and rewind** | Available | Rewind branches from an earlier turn; Tangent adds named, nestable side-conversations | [Tangent](https://kiro.dev/docs/cli/chat/tangent.md), [Rewind](https://kiro.dev/docs/checkpoints.md) |
| **Custom agents** | Available | Universal agent profiles, AI-assisted creation, and editing | [Custom agents](https://kiro.dev/docs/custom-agents.md) |
| **Permissions** | Available | Capability rules, scoped persistent policies, granular approvals, and session-wide trust | [Permissions](https://kiro.dev/docs/permissions.md) |
