# API keys

> Enterprise governance of API keys for Kiro

Developers can use API keys for executing automation scripts with Kiro CLI in their local machine or remote environment like CI/CD pipelines.

By default, the ability to generate API keys is turned off.

You control these restrictions through the Kiro console under **Settings** > **Kiro settings**.

## Enabling user-provided API keys

To enable users to configure their own API keys:
1. Open the Kiro console.
1. Choose **Settings**.
1. Under **Kiro settings**, toggle **Enable users to generate API keys** to **On**.

When enabled, users can login to Kiro portal and generate API keys.
