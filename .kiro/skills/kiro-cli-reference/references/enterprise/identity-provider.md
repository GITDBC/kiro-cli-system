# Connect an Identity Provider

> How to connect an identity provider with Kiro.

Kiro supports connecting to your external Identity Provider directly or through AWS IAM Identity Center.

![identity store selection](https://kiro.dev/images/enterprise/Kiro-profile-get-started.png)

Kiro supports connecting to the following identity sources:

- [IAM Identity Center](iam-identity-center)
- External Identity Provider (Direct)
  - [Okta](https://kiro.dev/docs/enterprise/identity-provider/okta)
  - [Microsoft Entra ID](https://kiro.dev/docs/enterprise/identity-provider/microsoft-entra)

Once the identity provider is connected, you can subscribe those users or groups to Kiro as described in the [subscription guide](https://kiro.dev/docs/enterprise/subscribe.md).
